# Папка дистрибутивов (distrib)

В эту папку автоматически помещается скомпилированный APK-файл Android-приложения (**Wi-Fi Эксперт**) после завершения сборки в **GitHub Actions** (`.github/workflows/build-apk.yml`).

### Файлы:
- `wifi-expert.apk` — готовый Android APK для установки на смартфон или планшет.
